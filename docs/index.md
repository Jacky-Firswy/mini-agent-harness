# ORG2 设计说明书

> 一本写给零基础读者的 ORG2 拆解书。
> 目标不是让你会**用** ORG2，而是让你在读完每个章节后，能回答一个问题：**这块东西为什么必须存在？**

---

## 这本书在讲什么

ORG2 是一个用 Tauri + Rust 写成的 AI 编程 Agent 产品。它的仓库有约 **130 万行代码**、**7,273 次提交**、**43 个 Rust crate**。

面对这种体量，大多数人的做法是去读 README。但 README 告诉你的是**它有什么功能**，不是**它为什么这样造**。

这本书换一种切法：**按"一条消息从进入系统到离开系统"的路径走一遍**，沿途把每一个零件拆开讲清楚。走完之后你再看任何 Agent 项目，都能自己判断它的骨架在哪、质量如何。

## 阅读前的三个约定

**第一，区分"源码实证"和"我的推断"。**
书里凡是从源码、提交记录、官方文档直接读到的，我标注来源路径。凡是我基于代码形态做的推理，会用这种框标记：

!!! warning "这是推断，不是源码原文"
    给出当前这个框，就说明这句话是我根据结构推测的，源码里并没有明写。你可以质疑它。

**第二，术语第一次出现时会解释。**
比如"事件流""金路径""幂等"这类词，第一次出现都会拆开讲。不存在"你自己去查一下"。

**第三，你可以随时写批注。**
每一章末尾都留了批注位。怎么写、怎么汇总、怎么标记版本，见 [怎么写批注](notes/how-to-annotate.md)。

### 第一部分 · 内核

这是全书的重心。**Agent 内核**决定了产品能力的上限，其余部分都是围着它转的。

| 章节 | 核心简介 |
|---|---|
| [Agent 内核](core/agent-kernel.md) | 什么是"内核"：一个没有界面、只会做"把消息喂给模型、把模型要的工具执行掉、再喂回去"的循环体。讲 `agent-core` 的四层分层、五个子目录各自管什么 |
| [一条消息的旅程](core/message-journey.md) | 从你在输入框敲下回车，到屏幕上出现第一个字，中间经过了 **7 个函数**。逐个讲每个函数负责什么、在哪一层、失败会怎样 |
| [事件流](core/event-stream.md) | 「事件流」到底是什么：模型不是一个字一个字"回"给你的，而是一堆碎片 delta。讲为什么要有一个 `StreamingBuffer` 把碎片攒成完整事件，以及早期"前端自己攒"的方案为什么必须被推翻 |
| [回合执行器](core/turn-executor.md) | 「一个回合」= 用户说一句话到模型停下来之间的全过程。讲驱动循环、流式执行、断线恢复、被截断恢复、重试退避、token 记账这六件事为什么必须拆成六个文件 |
| [工具系统](core/tools.md) | Agent 唯一能"动手"的地方。讲 `Tool` trait、工具注册表、工具策略（白名单/审批）、十一个能力分区，以及"给模型看的说明"和"给人看的说明"为什么要分开 |
| [Provider 层](core/providers.md) | 模型厂商的脾气各不相同。讲四个驱动（Anthropic 原生 / OpenAI 兼容 / OpenAI Responses / Codex OAuth）为什么不能合并，以及"永远不要用字符串比较 provider"这条硬规矩的由来 |
| [会话与状态](core/session.md) | 「会话」不只是聊天记录：它还持有模型选择、取消标志、工作目录、被读写过的文件清单。讲 18 个子模块分别守住哪一块状态 |

### 第二部分 · 能力层

内核只会"循环"，能力靠这一层"注入"进去。

| 章节 | 核心简介 |
|---|---|
| [记忆系统](intelligence/memory.md) | 模型本身不记事。讲五个子系统（学习、反思、向量检索、整理、工作区记忆）如何分工，以及"记住"这件事为什么需要五个模块而不是一个 |
| [Skills · MCP · Hooks](intelligence/skills-mcp-hooks.md) | 三种给 Agent 加能力的方式，以及它们的本质区别：Skills 是提示词、MCP 是协议、Hooks 是拦截点。讲各自的侵入性和代价 |

## 30 秒速览：ORG2 的骨架

如果你现在只想抓一个整体印象，看这一张图就够了。

```
                    ┌──────────────────────────┐
   你敲下回车  ────► │  state/   Tauri 命令入口   │
                    └────────────┬─────────────┘
                                 ▼
                    ┌──────────────────────────┐
                    │  core/session  AgentSession│  一次会话
                    └────────────┬─────────────┘
                                 ▼
                    ┌──────────────────────────┐
                    │  turn_executor  驱动循环   │  ◄── 回合
                    └───┬──────────────────┬───┘
                        ▼                  ▼
            ┌───────────────────┐  ┌──────────────┐
            │ providers  模型    │  │  tools  工具  │
            └─────────┬─────────┘  └──────┬───────┘
                      │                    ▼
                      │          ┌──────────────────┐
                      │          │ intelligence 能力 │
                      │          │ integrations 外部 │
                      │          └──────────────────┘
                      ▼
            ┌──────────────────────────────────────┐
            │ foundation  总线 · 持久化 · 流缓冲     │
            └──────────────────────────────────────┘
                                 │
                                 ▼
            ┌──────────────────────────────────────┐
            │  事件流 ── WebSocket ──► 前端界面      │
            └──────────────────────────────────────┘
```

这张图里每一根线，书里都有一章专门讲。从 [Agent 内核](core/agent-kernel.md) 开始。
