    ORG2 设计说明书¶

    一本写给零基础读者的 ORG2 拆解书。 目标不是让你会用 ORG2，而是让你在读完每个章节后，能回答一个问题：这块东西为什么必须存在？

    这本书在讲什么¶

    ORG2 是一个用 Tauri + Rust 写成的 AI 编程 Agent 产品。它的仓库有约 130 万行代码、7,273 次提交、43 个 Rust crate。

    面对这种体量，大多数人的做法是去读 README。但 README 告诉你的是它有什么功能，不是它为什么这样造。

    这本书换一种切法：按"一条消息从进入系统到离开系统"的路径走一遍，沿途把每一个零件拆开讲清楚。走完之后你再看任何 Agent 项目，都能自己判断它的骨架在哪、质量如何。

    阅读前的三个约定¶

    第一，区分"源码实证"和"我的推断"。 书里凡是从源码、提交记录、官方文档直接读到的，我标注来源路径。凡是我基于代码形态做的推理，会用这种框标记：

    这是推断，不是源码原文

    给出当前这个框，就说明这句话是我根据结构推测的，源码里并没有明写。你可以质疑它。

    第二，术语第一次出现时会解释。 比如"事件流""金路径""幂等"这类词，第一次出现都会拆开讲。不存在"你自己去查一下"。

    第三，你可以随时写批注。 每一章末尾都留了批注位。怎么写、怎么汇总、怎么标记版本，见 怎么写批注。

    全书目录¶

    导读¶

    章节 核心简介
    这本书怎么读 三条不同的阅读路线（只想懂概念 / 想照着做 / 想改它的代码），以及每类读者应该跳过哪些章节
    ORG2 到底是个什么系统 一句话定位 + 它同时是四种东西（Agent 内核、IDE、编排平台、记录系统），以及这四者为什么会打架

    第一部分 · 内核¶

    这是全书的重心。Agent 内核决定了产品能力的上限，其余部分都是围着它转的。

    章节 核心简介
    Agent 内核 什么是"内核"：一个没有界面、只会做"把消息喂给模型、把模型要的工具执行掉、再喂回去"的循环体。讲 agent-core 的四层分层、五个子目录各自管什么
    一条消息的旅程 从你在输入框敲下回车，到屏幕上出现第一个字，中间经过了 7 个函数。逐个讲每个函数负责什么、在哪一层、失败会怎样
    事件流 「事件流」到底是什么：模型不是一个字一个字"回"给你的，而是一堆碎片 delta。讲为什么要有一个 StreamingBuffer 把碎片攒成完整事件，以及早期"前端自己攒"的方案为什么必须被推翻
    回合执行器 「一个回合」= 用户说一句话到模型停下来之间的全过程。讲驱动循环、流式执行、断线恢复、被截断恢复、重试退避、token 记账这六件事为什么必须拆成六个文件
    工具系统 Agent 唯一能"动手"的地方。讲 Tool trait、工具注册表、工具策略（白名单/审批）、十一个能力分区，以及"给模型看的说明"和"给人看的说明"为什么要分开
    Provider 层 模型厂商的脾气各不相同。讲四个驱动（Anthropic 原生 / OpenAI 兼容 / OpenAI Responses / Codex OAuth）为什么不能合并，以及"永远不要用字符串比较 provider"这条硬规矩的由来
    会话与状态 「会话」不只是聊天记录：它还持有模型选择、取消标志、工作目录、被读写过的文件清单。讲 18 个子模块分别守住哪一块状态

    第二部分 · 能力层¶

    内核只会"循环"，能力靠这一层"注入"进去。

    章节 核心简介
    记忆系统 模型本身不记事。讲五个子系统（学习、反思、向量检索、整理、工作区记忆）如何分工，以及"记住"这件事为什么需要五个模块而不是一个
    Skills · MCP · Hooks 三种给 Agent 加能力的方式，以及它们的本质区别：Skills 是提示词、MCP 是协议、Hooks 是拦截点。讲各自的侵入性和代价

    第三部分 · 外部世界¶

    Agent 要能被人从各种地方叫起来。

    章节 核心简介
    渠道与网关 Telegram / Discord / Slack / 企业微信 / 微信五个渠道，以及中间的网关。讲「消息总线」的入站用 mpsc、出站用 broadcast 这个不对称设计
    自动化触发 让 Agent 不等你开口就自己动起来。讲定时触发、文件变化触发，以及"触发"和"对话"在架构上的根本差别

    第四部分 · 数据与界面¶

    章节 核心简介
    持久化 SQLite + 文件存储。讲一个反直觉的设计决定：没有 migrations 目录、没有版本表，靠"容忍重复列"做到幂等
    前端与 Tauri Rust 后端怎么和 TypeScript 前端说话。讲 Tauri command、IPC Channel、以及为什么 43 个 crate 里有一批是专门给前端用的
    测试与自进化 ORG2 声称能"自我进化"，靠的是 Agent 能自己跑 E2E 测试。讲这个闭环成立需要哪些条件，以及它的风险

    第五部分 · 建造史¶

    章节 核心简介
    五个阶段 从 2026-06-01 到 2026-10-11，七个两千多次提交可以切成五段。讲每一段在解决什么，以及三条贯穿始终的主线

    附录¶

    章节 核心简介
    五层架构规则速查 把 ARCHITECTURE.md 里的硬规矩提炼成一张卡片，写代码前扫一眼
    术语表 全书出现的所有专有名词，按拼音排序
    我自己的 harness 对照 你那个 600 行的 mini-agent-harness 和 ORG2 逐层对照表：哪些已经对齐，哪些差距最大
